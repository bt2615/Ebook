# Ebook
ASG DESCOMPLICADO - Transformando o Mundo com Pequenas Ações
📒 Descrição
Buscando conhecer e utilizar ferramentas de IAs Generativas, o projeto abaixo foi criado para desenvolver as habilidades em IA e produzir um ebook sobre ASG destinado a Jovens brasileiros dispostos a impactar o mundo com suas ações.

🤖 Tecnologias Utilizadas
CHATGPT: criação da imagem de capa, título e conteúdo do livro. 
POWERPOINT: diagramação.

🧐 Processo de Criação
O CHATGPT foi o parceiro na jornada de  criação da imagem de capa, título e conteúdo do livro (introdução, capítulos, conclusão e agradecimento). Também criei uma imagem para a capa no app Night Cafe mas acabei optando pela imagem do Dall-e 3. 
Para diagramação e ajuste de layout, foi utilizado o PowerPoint e suas funcionalidades.

🚀 Resultados
O ebook foi gerado com sucesso, sendo este processo de criação utilizado para aprendizagem de IAs.
